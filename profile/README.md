**FactorySemantics MES** — an open-source, modular, agent-native Manufacturing Execution System. Apache-2.0.

- Product: [factorysemantics-mes](https://github.com/factorysemantics/factorysemantics-mes) · `pipx install factorysemantics-mes`

- Talk: [Discussions](https://github.com/factorysemantics/factorysemantics-mes/discussions)
